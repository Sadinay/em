# 单进程 FEMM 接入设计与当前进度

隔离worker形式的 `ClonalgEngine -> Evaluator -> FEMM COM` 基线现已实现，并完成一个历史染色体的0°对照。以下仍作为扩大验证规模前的执行原则。

## 建议调用边界

1. CLONALG提交不可变染色体；缓存先用180字符兼容键命中或去重。
2. `FemmEvaluator` 创建唯一工作目录和任务ID，原子写入任务清单。
3. 运行现有Python `historical_inset` 解码与预检查；硬拒绝不启动FEMM。
4. 通过预检后，从只读基准FEM复制任务模型，只修改设计域。
5. 一个Windows进程独占一个FEMM实例，顺序计算 `[0,3,6,9,12,15]`。
6. 每角度记录建模、网格、求解、后处理时间，并校验转矩为有限数。
7. 成功结果先写临时JSON，再原子替换正式结果；失败保留基因、拓扑、FEM和分类日志。
8. 超时或COM断连时终止并重启该唯一实例；重试次数有上限，最终返回明确惩罚值。

## 首轮验证门槛

- 固定模型重复运行；
- 一个历史染色体的几何和材料逐项检查；
- 五个人工个体；
- 20个个体的小规模CLONALG；
- 50个个体连续稳定性测试。

只有单进程达到可重复、可恢复且无残留进程后，才设计两个独立进程、独立FEMM实例和独立目录的测试。不能用线程共享同一COM实例。

## 必须保持分离的实验

- `historical_inset` 是兼容基线。
- `merged_copper_v5` 必须作为独立几何模式，对同一染色体比较几何、匝数、连通性、平均转矩、脉动率和J，不直接替换基线。
- 六角度只是历史兼容扫描。需另建密角度实验，量化六点平均转矩和脉动率相对密扫描的误差，再决定最终科学计算角度数。
