# 900/1000 无效个体原因分析

数据源：`C:\Users\26096\Desktop\em\FP\IA_test_Float\trace_all_20260306_174158.mat`。统计单位是保存的种群位置；重复染色体仍按其在每代出现的位置计数。

## 结论

- 1000 个位置中，900 个被拒绝，100 个有效。
- 小铜岛触发 900 个，浮铁触发 896 个。
- 同时触发两条规则 896 个；仅小铜岛 4 个；仅浮铁 0 个。
- 因而在这份 trace 中，铜规则参与了全部 900 次拒绝；不能据此断言铜编码在其他种群中必然是唯一主因。
- 共 451 个唯一染色体；其中 450 个唯一无效、1 个唯一有效。
- 每一代均为 9/10 被拒绝。100 个有效位置实际都是同一个精英染色体的重复保留。

## 当前源码与历史输出的回归边界

- 小铜岛单元数：1000/1000 精确一致。
- 浮铁单元数：901/1000 精确一致；99 个位置、55 个唯一染色体不一致。
- 最终拒绝布尔判定：1000/1000 一致，因为上述不一致位置仍被小铜岛规则拒绝。
- 用历史 MAT 内保存的两种计数代入 `1e6 + 50*nFloatCu + 50*nFloatFe`：900/900 精确一致。
- 用当前源码规则重新计算完整无效 J：801/900 一致。

这说明目标公式和铜岛实现已被历史数据验证；现存 `detect_floating_iron.m` 不能解释全部历史浮铁计数。文件内没有算法版本号或运行时源码快照，因此该差异记录为源码/输出版本漂移，不能通过擅改 Python 规则来掩盖。
