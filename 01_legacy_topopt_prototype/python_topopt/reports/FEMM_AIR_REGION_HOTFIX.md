# merged_copper_v5 封闭空气区域修复

## 根因

实际MATLAB入口 `eval_design_femm.m` 调用
`femm_apply_design_bits_rep6_inset_merge_cu_island_inset_v5_corner_tri.m`。
V5先按铜格是否带空气建立 `key_air_band`，按格子连通保留一个标签并删除内部边界，随后只使用 `xAirList(1)`。该逻辑假设格子连通等价于实际内缩铜多边形外空气带连通。

失败父本 `P0018` 证明该假设不成立：格子规则得到2个空气带连通块，实际几何存在3个封闭空气区域，导致FEMM报错 `Material properties have not been defined for all regions`。

早期MATLAB V4会遍历每个铜格的全部 `xAirList`，但不进行V5空气带合并，因此较稳健但网格更大。问题来自MATLAB V5优化本身，不是Python排列或染色体翻译错误。

## 修复

- 在极坐标设计域构造与V5建模命令相同的铜多边形。
- 计算“带空气铜格并集减去铜多边形并集”。
- 按实际几何连通区域选择一个确定性的内部代表点。
- 每个真实空气区域放置且只放置一个Air标签。
- 铜、铁、普通空气和安全的空气带内部边界仍保持合并。
- prepared模型加入几何构建版本，旧缓存自动失效。
- 单候选最终物理失败后留档并跳过；连续3个失败才暂停整个任务。
