# merged_copper_v5 FEMM优化重建报告

## 实现范围

按当前优化入口 `eval_design_femm.m:55-56` 调用的 `femm_apply_design_bits_rep6_inset_merge_cu_island_inset_v5_corner_tri.m`，新增独立模式：

```text
geometry_mode: merged_copper_v5
```

历史兼容模式 `historical_inset` 未被替换。V5实现包括：

- 背景空气和铁按4邻接连通块合并；
- 铜格按连通块合并，删除同铜材料内部边界和孤立节点；
- 铜连通块只保留一个材料标签；
- 标签匝数为 `连通块格数 × 每格匝数`；
- 相邻铜格正邻边不内缩；
- 只在铜岛外边界保留空气带；
- 对角缺铜时生成V5角部空气带和角标签；
- 常半径铜边界使用圆弧，镜像扇区交换弧端点；
- 六扇区相序、镜像和电流计算保持原代码定义。

## 结论和边界

同材料区域合并确实降低了几何和网格复杂度，是本次约45%求解时间下降的主要原因。圆弧数量增加是因为V5把常半径铜边界表达为真实圆弧，但线段、总边界、标签和最终网格仍显著减少。

0°转矩变化约0.197%，说明V5不能当作严格数值等价的纯网格优化。它还改变了铜岛外边界、角空气带和标签/匝数表达，所以必须继续作为独立实验模式。

当前只完成0°对照。平均转矩和转矩脉动必须至少完成历史六角度扫描后才能比较；单点脉动率必为0，不具有比较意义。
