# NSGA-II—CNN—FEMM：续跑至300代

新增两百代验证866个基因。最高平均转矩提高0.044%，最低波动降低27.77%。两端是**不同结构**，不能合称为一个同时具备两个极值的设计。转矩≥4.2 N·m时，最低波动仅降低3.68%。最高转矩结构的波动从第100代的0.214192变为第300代的0.310853 N·m，体现明显取舍。

当前最低波动结构：第180代，磁体格数103，Tavg=4.059597 N·m，ΔT=0.005495 N·m。最高转矩结构：第139代，磁体格数108，Tavg=4.261178 N·m，ΔT=0.310853 N·m。转矩≥4.2 N·m且波动最低的结构：第210代，Tavg=4.204365 N·m，ΔT=0.063461 N·m。

新增两百代的主CNN预测误差：平均转矩MAE=0.005683 N·m；波动MAE=0.047314 N·m。这是GA主动选取的验证样本，**不代表独立测试集精度**；波动误差显著大于已得到的极低波动值，低波动方案必须按FEMM真值判断。
