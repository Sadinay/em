## 可以带给导师的结论

1. 找到截图参数的实际差异：02 原始 `IPMSM.fem` 的 `sliding_airgap` 保存为 Inner Angle≈15°、Outer Angle=0°；03 原始 `SPMSM_discrete.fem` 保存为 0°、0°。两者边界类型都是 6，即 Periodic Air Gap。

3. 两份 MAT 的可解码普通参数中，没有找到直接对应 Inner Angle/Outer Angle 的独立命名设置，也没有找到明确的“电流转动/滑动气隙转动”切换开关。MATLAB 函数句柄捕获工作区以 opaque 对象保存，本次没有完整解码其中的隐藏内容，不能声称 MAT 内绝无其他信息。
4. 当前本地 02、03 Python 重算脚本均同时修改 Inner Angle 和三相电流。历史 MATLAB 算法是否不同，仍需要原始求解函数证明，不能用后来编写的 Python 脚本替代历史证据。
5. MAT 内确实存在变化的几何角参数，尤其 `inp.theta`、`inp.PMangle`，以及 03 新增的 `inp.PM_angle`、`inp.angle_tmp`。其中 `inp.theta` 已与 MaterialPosition 坐标核对，是设计格的角向间隔，不能作为机械扫描步长。

## 截图两个角度的含义

对于当前内转子结构，Inner Angle 是气隙内侧相对绘制位置的机械角位移，Outer Angle 是外侧相对绘制位置的机械角位移。通常外侧为定子，固定为 0°，通过改变内侧角度模拟转子运动。

```matlab
mi_modifyboundprop('sliding_airgap', 10, theta_m); % Inner Angle，机械角，度
mi_modifyboundprop('sliding_airgap', 11, 0);       % Outer Angle，机械角，度
```

这里 10、11 是属性编号。它们不是转角值，也不是边界类型。边界类型 6 表示 Periodic Air Gap。

滑动气隙运动改变求解中的转子相对位置，FEMM 绘制的几何轮廓不必在屏幕上转动。因此不能凭转子轮廓没有旋转，判断模型只改了电流。

官方依据：[FEMM 转子运动说明](https://www.femm.info/doku/doku.php?id=rotormotion)、[FEMM 手册中的 mi_modifyboundprop 属性表](https://www.femm.info/doku/lib/exe/fetch.php?media=upload%3Afiles%3Amanual.pdf)。

## 当前 Python 重算做了什么

02：`02_new_ipmsm_project/femm_6point_validation/scripts/solve_one_angle.py`。

03：`03_new_spmsm_project/femm_zone/scripts/solve_one_angle.py`。

两者默认均执行：

```text
Inner Angle = theta_m
Outer Angle = 原始模板的 0°
theta_i = 4 * theta_m
Ia = 3.5*cos(theta_i)
Ib = 3.5*cos(theta_i - 120°)
Ic = 3.5*cos(theta_i + 120°)
```

03 脚本额外提供 rotor_angle_factor、current_angle_factor 和 current_phase_offset_deg，用于方向/相位诊断；这些是当前 Python 接口选项，不能说是从历史 MAT 恢复出的设置。默认分别为 1、1、0。

已有求解文件的交叉核对：

- 02：`femm_6point_validation/corrected_pm_direction/angles_3deg/angle_003/model.fem`。
- 03：`femm_zone/results/history_replay_validation/median_tavg/angle_3/model.fem`。

两者均为 Inner=3°、Outer=0°，三相电流均为约 `[3.42351660256832, -1.081559480312315, -2.3419571222560025] A`，与上述默认公式一致。

修改 Inner Angle 是赋新值，而不是在原值上累加。当前 02 脚本给它设 3°时，会覆盖原始模板的 15°，不会变成 18°。

## 电流角扫描与转子位置扫描的物理区别

| 操作 | 改变内容 | 主要含义 |
|---|---|---|
| 固定转子位置，只改电流相位 | 定子电流磁场相对转子的角度 | 固定位置下的电流角/负载角特性 |
| 改转子位置，电流瞬时值固定 | 转子与槽、与定子电流场的相对位置 | 固定励磁条件下的位置特性 |
| 改转子位置，同时令电流相位随 P*theta_m 更新 | 维持选定的电流相位关系并遍历槽极位置 | 同步工况下的转矩位置波形 |

实际 dq 电流角还需考虑绕组磁轴、转子磁轴初始角及相序，不能直接把 Python 的 offset=0 解释为 id=0。只转电流一般不能替代带槽电机的转子位置扫描。
