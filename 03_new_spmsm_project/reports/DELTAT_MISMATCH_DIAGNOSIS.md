# SPMSM `DeltaT` 偏差诊断

日期：2026-09-02

## 结论

当前明显偏差不是由120位基因到 FEMM 结构的映射错误造成的。映射后，6个代表基因的平均转矩与历史值高度一致；真正的问题有两层：

1. 首轮验证把历史 `DeltaT` 直接当成了单位为 N·m 的绝对峰峰值 `max(T)-min(T)`。但本地同一台 8极12槽 SPMSM 的 MATLAB 扫描程序 `01_legacy_topopt_prototype/FP/CLONALG/scantorque.m` 明确定义为：

   ```matlab
   T_avg    = mean(T);
   T_ripple = (max(T)-min(T))/max(abs(T_avg),1e-6);
   ```

   因此，历史 `DeltaT` 很可能是无量纲相对转矩脉动率，而不是 N·m。原报告及脚本中的 `delta_t_nm` 命名不能作为单位证据。

2. 改用相对脉动率后，6个样本的平均相对误差由 158.77% 降到 34.20%，但仍未达到可复现标准。这说明“口径错误”是主要问题之一，却不是全部问题。历史实际调用的 `fitness_GA5_SPMSM.m` 不在当前目录，MAT 里同时保存了 `steps=6` 和 `stps=72`，也没有保存每个个体的原始转矩序列，因此剩余的历史取样与后处理细节目前无法唯一恢复。

## 已排除的原因

### 基因—结构对应错误

- 120个基因对应 `6径向 × 20角向`；
- 每个基因精确对应 FEM 中四个对称 block label，共480个标签；
- 最大坐标误差仅 `1.52×10^-14 mm`；
- `gene=1` 的数量与 `VolumePM` 在末代612/612个个体完全一致；
- 成熟样本平均转矩最大相对误差仅约1%，说明材料位置和整体电磁尺度正确。

### 转子或电流方向

保持已验证尺度时，转子与电流同时反向只相当于波形反向遍历；只反向其中之一会使平均转矩误差扩大到约61%或180%。方向不是根因。

### 统一电流相位偏移

对3个成熟样本测试电角度偏移 `-30,-15,0,+15,+30°`：

| 电流相位偏移 | 平均 Tavg 相对误差 |
|---:|---:|
| -30° | 99.94% |
| -15° | 47.97% |
| 0° | 0.70% |
| +15° | 41.89% |
| +30° | 73.86% |

只有 `0°` 与历史平均转矩一致，所以不能为了拟合 `DeltaT` 任意调相位。

### 3°与2.5°取样

3°六点与2.5°六个不重复点给出的结论相同；把两套结果合并成11个角度后，相对脉动率的平均误差仍约34.10%。端点重复或这两种粗取样差别不是根因。

### 转矩积分方式

已用保留的36个 `.ans` 对比滑动气隙积分和转子/设计块的 `mo_blockintegral(22)`。两者的相对波形非常接近：气隙积分按相对口径的平均误差为34.20%，块积分为34.90%。换积分方式不能解释历史差值。

### 铁心材料

将模板的非线性 Pure Iron 改为 MAT 参数中的线性 `mu=4000` 后，3个成熟样本的平均转矩误差为0.92%，绝对 `DeltaT` 误差反而约103.42%，未改善问题。

## 目前能够确认和不能确认的部分

能够确认：

- 120位基因的空间顺序、四对称复制和 `0=Air / 1=N38 PM`；
- 当前 FEM 模板可以正确生成对应结构；
- 当前求解的转子方向、电流相序和整体转矩尺度；
- 历史平均转矩可以高精度重算。

尚不能确认：

- `fitness_GA5_SPMSM.m` 中 `DeltaT` 的最终公式；
- `steps=6` 与 `stps=72` 在历史程序中分别控制什么；
- 历史程序使用的确切角度序列、是否滤波，以及是否还有归一化或百分数变换；
- 当前提供的 `SPMSM_discrete.fem` 是否与生成 `workspace_200.mat` 时的模板、网格和 FEMM 版本完全相同。

## 对后续测试的建议

平均转矩通道可以继续使用。`DeltaT` 通道暂时不要标成 N·m，也不要把当前重算绝对峰峰值与 MAT 中的 `DeltaT_all` 混合训练。最有效的补充证据是以下任意一种：

1. 原始 `fitness_GA5_SPMSM.m`；
2. 任意一个历史个体的六点或72点原始转矩数组；
3. 任意一个历史求解后保存的 `.fem` 与 `.ans`。

拿到其中一项即可直接确定剩余口径，而不需要继续盲目枚举参数。
