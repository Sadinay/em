## 4. 核验基因身份、清单和数据角色

以完整 gene_id 和最终 120 位 bits 关联结果与清单，不按 CSV 行号、文件夹遍历顺序或 ID 前缀关联。

要求：

1. bits 仅含 0/1，长度 120；使用项目现有基因哈希定义重算 gene_id。
2. 编码保持 `gene_index = angular_index × 6 + radial_index`；逻辑网格等价于 bits.reshape(20,6).T；每基因变量映射四处实际设计区域。
3. train_G/F 各自内部唯一。两者允许 101 个重合，并共享同一物理标签。
4. 新 train 与 dev/test 精确互斥，dev 与 test 互斥；核验既定生成家族划分。P 的父代属于旧 train，不能声称它们是完全未见父代的测试。
5. 新样本与完整已知历史清单只做身份/精确去重检查，不用旧 test 的标签或特征拟合任何分析规则。
6. 冻结队列与结果集合逐一对账：成功、缺失、失败、重复、队列外结果分别列出。同基因同工况重复记录只有在一致性核验后合并；冲突记录隔离。
7. memberships 与 G/F/dev/test 清单一致；保留 source、family_id、生成参数、raw_bits/修正记录和原选择顺序。

不要为凑齐数量替换失败样本或重新分配 dev/test。测试数据可做完整性、身份和物理标签核验，之后单独存放；本阶段不做测试预测、测试误差排序或基于测试结果的模型/规则选择。

## 5. 核验物理口径与六角度标签

应与已核验的 03 物理口径一致：

| 项目 | 冻结设置 |
|---|---|
| 相对机械行程 | 0、3、6、9、12、15° |
| 实际 sliding_airgap 内角 | 29、32、35、38、41、44° |
| 外角 | 0° |
| 三相电流 | 峰值 3.5 A，电角度从 0°起，随相对机械行程按 4 倍推进 |
| 初始 29° | 只加到机械内角，不再加入电流初相位 |
| 问题定义 | Planar、mm、Frequency=0、Depth=36 mm |
| 网格/精度 | Min Angle=15°、SmartMesh=1、Precision=1e-8 |
| 转矩 | mo_gapintegral('sliding_airgap',0)，倍率 1 |
| 标签 | Tavg=六点算术平均；DeltaT=六点最大值−最小值；均为 N·m |

不要混用 01/02 项目配置、旧 −2 倍率、百分比脉动定义或不同角度设置。

逐个成功基因检查：六个角度齐全且各一次；转矩为有限实数；从角度值重新计算 Tavg/DeltaT，与汇总标签核对。比较容差依据保存精度确定并记录；如采用 1e-6 N·m，应明确它是核验容差，不能通过放宽容差掩盖差异。DeltaT 应非负；负 Tavg 本身不等于无效样本。

不得只根据 report.json 的成功计数验收，也不得把六个机械角度当成六个独立训练样本。

已有 `femm_zone/workspaces/pilot20_cross_device_check_20260909/核验报告.md`：20 个小批记录通过核验，其中两基因/12 角度进行了独立重算并一致。报告还说明对方修复了 COM 通信分支，加入成功后的文件清理与缓存凭据，运行指纹因此改变。请复用这些证据，但不能把这次两基因抽查写成全量 3299 个都独立复算。

工况指纹或运行器哈希不同，先比较其实际物理字段和版本差异；路径、COM 修复、清理策略变化不能自动等同于物理变化。跨工况不盲目合并。缺原始 FEM/ANS 不自动判成无效，但必须区分“可复查原始求解文件”和“依据保留记录核验”；缺波形且无逐角度结果时，不能声称已复核六点标签。

本阶段进行已有数据核验，不默认启动新的 FEMM 求解。发现缺失或冲突时，交付明确清单及所需最小补救动作。

## 7. 冻结正确的旧模型 f0，做基线评估

模型身份：`polar90_224 / vgg16_v2 / seed_20260903`，旧 train=40000。

预期目录：`03_new_spmsm_project/cnn_zone/models/v3_40000_6runs/polar90_224/vgg16_v2/seed_20260903/`，权重 `best_checkpoint.pt`。按实际本机路径定位，并核验 config/result/checkpoint，记录哈希。若找不到正确权重，完成数据核验部分后明确报告，不用其他架构或随机权重替代。

旧划分：`cnn_zone/outputs/splits/scheme_a_tavg_bands_train40000_val6483_test6483.npz`。旧 train/validation/test 身份保持不变。

使用 eval/inference 模式、关闭 Dropout、不更新权重或归一化状态。目标顺序为 Tavg、DeltaT，按 checkpoint 自带 target_mean/target_std 做逆标准化；不能用新样本统计量解码旧模型，也不能对已经逆标准化的输出再变换一次。

复用同模型、同划分的已有旧验证结果做一致性检查；如果只能找到旧测试指标，不用它替代旧验证指标，也不在本阶段为此重跑测试。批量大小按显存选择，记录实际设备、精度和耗时；不要求重新训练或提取全部 2 万候选特征。

评估对象：

- 旧 validation 6483：确认原有水平与推理链路。
- train_G 1400、train_F 1400：旧模型对这些补样结构的初始误差，用于训练前诊断。
- 公共 dev 200：共同的新结构开发验证基准。

对重复基因可只推理一次再映射到各组。这里 train_G/F 尚未被旧 f0 用于训练，因此可以用于旧模型诊断；后续更新模型在这些样本上的误差应明确标为训练误差，不能当作泛化成绩。

## 8. 指标、结构差异与图表

Tavg 与 DeltaT 分别报告 N、MAE、RMSE、中位绝对误差、P90/P95 绝对误差、最大绝对误差和平均有符号误差。统一残差定义为预测−真实。R² 和 Spearman 排序相关可作为辅助；样本不足或目标恒定时写 NA 并解释，不强行填 0。

主要比较：

1. 旧 validation 与公共新 dev 的整体及分目标误差。
2. 新数据 U/L/B/P 四来源分别的误差，并保留样本数。公共 dev 每类只有 50 个，尾部估计和小差异结论需谨慎。
3. train_G 与 train_F 各自的来源组成、磁体格数/面积、到旧 train 的最近 Hamming 距离，以及各自旧模型误差。合并展示时 G/F 交集去重。

最近 Hamming 只作为解释和审计，不把它当作准确率保证。已有距离可在身份核验后复用；新计算时参考旧 train，不使用旧 test。物理面积采用已核验区域映射，不把格数直接称作面积。

G 的固定位置 WL0/1 主要衡量局部材料失配及其一圈邻域，没有显式赋予桥接断裂、气隙位置或长程连接特殊权重。F 特征可能继承旧 CNN 的盲区。报告必须保留这两个限制，不能把它们当作已经验证的物理距离。

图表以少量直接支持结论的图为主：

- 两目标真实值−预测值散点图，区分旧 validation 与公共新 dev，带 y=x 参考线。
- 公共 dev 按 U/L/B/P 的绝对误差分布图，两目标分开。
- G/F 来源组成，以及可用的磁体用量、最近旧样本距离分布。
- 少量新 train/dev 的典型大误差结构图（6×20＋原 renderer 对应材料图），旁列来源、真实值、预测值和误差。

例图只从 train/dev 选取，不从最终 test 挑案例。颜色、坐标、单位统一；不要把近零目标的百分比误差作为主指标，也不要只展示平均值掩盖严重错误。

比较结论要克制：G 与 F 选出的数据不同，旧模型在某组误差更高，只说明那组对旧模型更难，不能据此宣布该选样方法更有效。方法优劣需要后续训练后在相同验证/测试样本上比较。

## 9. 怎样回答“每组 1400 会不会太少”

本阶段只能量化旧模型与新增结构之间的差距，以及数据是否准备好，不能直接证明补样数量足够或不足。

后续每个更新模型计划使用 40000＋1400 个训练样本。简单等权合并时，新增样本占约 3.38%；这是样本占比，不代表它们只能贡献 3.38% 的实际梯度，也不意味着每轮没见到新样本。是否需要提高新样本权重，应在统一训练方案中开发，并同时监测旧 validation，不能现在随意为 G/F 采用不同设置。

在报告的下一阶段建议中：先做原定 G/F 两个更新模型的公平对照，使用冻结 dev；若要检查样本量趋势，可提出使用已有选样顺序中嵌套的 700 与 1400 训练子集，保持训练设置可比。这只是后续实验建议，本任务不自动启动训练或新 FEMM。

不能仅因旧模型在新样本上误差大就建议立即新增几千次 FEMM；这也可能反映旧分布偏差、表示局限或推理/标签问题。也不能因为数据有 3299 个就宣称全面泛化。当前输出应把数据问题、模型初始差距和待训练验证的问题分开。
