# 同材料内部边界安全删除验证

## 结论

安全删除实现和三类基因对照已经完成，但**未达到严格数值一致性要求，正式默认保持关闭**。未启动 100 代搜索。

删除仅发生在 120 位设计域的四份对称映射内部。相邻单元必须具有相同材料、组、回路、匝数、网格约束等属性；永磁体还必须具有相同磁化方向。扇区边界、滑动气隙、外轮廓及磁化方向不同的永磁体边界均保留。合并连通区域只保留一个 block label，并删除因删边产生且不再被任何边引用的节点。

## 六角度 FEMM 对照

工况完全一致：机械角度 29、32、35、38、41、44 度。预先采用的严格容差为每角度和汇总指标绝对误差不超过 0.0005 N·m，或相对误差不超过 0.02%。删除的内部边界在材料与区域属性上物理等价，但删除后 FEMM 会重新三角化；“物理等价”不能直接等同于“离散求解结果已被证明一致”。

三组共 36 次求解中，合并前总耗时 84.52 秒，合并后 58.69 秒，总体缩短 30.6%，平均解网格节点减少 38.4%。高磁体案例因相邻角向磁体的磁化方向不同而保留了 408 条边界，几何简化很少，因此单例没有提速；这是安全条件生效的预期结果。速度收益已证实，但严格数值一致性没有证实。

为判断差异是否只是可接受的网格离散误差，随后尝试了两个统一细化控制：提高 `MinAngle` 的试验在求解时失去当前磁场输入；为设计域统一设置 `0.05 mm²` 最大单元面积的试验在第一个基因、基准模型、29° 的 `mi_analyze` 阶段被 FEMM 模态错误阻塞，只有输入 `.fem`，没有 `.ans` 或结果。为避免继续弹窗，实验已停止且未继续批量求解。由于没有取得网格收敛证据，目前不能仅通过放宽容差把结果判为通过。

完整逐角度转矩、哈希、耗时、网格节点和删除统计见 `validation.json`。每个角度的 `.fem`、`.ans` 和 `result.json` 保存在对应案例目录中，可独立复核。

## 验证与保护

- 静态测试验证全空气合并数量、永磁体磁化方向边界保留、混合连片模型段计数。
- 项目 FEMM/GA 相关测试共 27 项通过。
- NSGA-II 两代自检通过，暂停/恢复行为保持不变。
- 合并器源码哈希与策略状态进入 FEMM 物理指纹；旧缓存不会跨策略误复用。
- GA 适配器中的合并开关保持 `False`。如将来完成收敛验证并启用，重试路径会重新写入已登记的合并后字节，不会退回未优化模板。
