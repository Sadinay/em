# IPMSM基因拓扑图像化：阶段1–3审计报告

## 阶段结论

阶段1–3已经通过，可以进入“实现训练器并做256样本过拟合”的下一阶段门槛。本阶段没有正式训练CNN，没有批量调用FEMM，也没有保存海量图片。

## 1. 文件与编码

- MAT记录为601个状态×504个体，共302,904条历史记录；不能解释为302,904次相互独立的FEMM求解。
- `population_noChange_all`是修正前raw gene。
- `population_all`是修正后、与历史Tavg/DeltaT直接对应的FEMM输入。
- 两位编码高位在前：`code=2*bit[2i]+bit[2i+1]`。
- 每连续10个单元沿半径变化，向量索引为`angle_index*10+radius_index`。
- CNN逻辑网格轴为`[radius,angle]`。

FEM统计：512节点、470直线段、447圆弧、1孔、411个block label、104个材料属性、3个电路。

## 2. 材料映射证据

最终采用：`0=Air`、`1=N38 permanent magnet`、`2/3=Pure Iron`。

证据链：

1. `VolumePM`与corrected基因中code 1数量在第1–600代完全一致。
2. `MaterialPosition[100,8]`的400个坐标与FEM block label逐点精确匹配。
3. corrected候选的单拓扑六角度FEMM重放中，`0=Air,1=PM,2/3=Iron`的Tavg梯形平均相对历史误差为0.186%，明显优于其他空气位置映射的约29%–40%。
4. code 2/3均写为参考FEM的非线性Pure Iron；改成线性铁后结果出现约92%的Tavg误差。

参考`IPMSM.fem`本身不是历史库中的某条完整染色体：raw和corrected最近匹配都相差32个单元。因此材料关系不是通过“找到完全相同参考基因”证明，而是由VolumePM、FEM标签和数值重放共同证明。

- raw四状态唯一：170,251；无冲突169,917。
- corrected四状态唯一：159,921；无冲突156,167。
- corrected物理三状态唯一：150,422。
- 物理标签冲突隔离：3,951。

## 4. 真实90°语义查找表

查找表来自一次性FEMM解网格的99,936个节点和198,019个三角形。每个三角形带有真实block-label ID，像素通过三角形定位映射，不是10×10插值。

224×224查找表：

- 物理范围：0–64 mm×0–64 mm；像素间距0.285714 mm。
- 设计域像素：6,729。
- 每个基因至少42、最多96个像素。
- 400个设计block label中心全部落入正确三角形区域。
- 100个基因全部保留，每个基因对应4个FEM区域。

四副本沿物理角度递增顺序为：

```text
0°–22.5°   base
22.5°–45°  mirror
45°–67.5°  base
67.5°–90°  mirror
```

永磁体极性编码：0°–45°径向向内，45°–90°径向向外。

## 5. 内存渲染与闭环验证

实时渲染链：

```text
[B,100] gene codes
→ pixel_gene_id数组索引
→ [B,8,224,224]语义张量
→ 后续CNN
```

默认通道为design air、PM inward、PM outward、design iron、fixed air、fixed iron、winding和geometry mask。

3个历史corrected基因已分别生成实际修改后的FEM文件并与内存图对照：

- generation 17 / individual 55：400区域错配0，PM方向误差0°。
- generation 208 / individual 74：400区域错配0，PM方向误差0°。
- generation 467 / individual 392：400区域错配0，PM方向误差0°。

同一基因重复渲染逐像素完全一致。CPU单独渲染1024样本约0.884秒，即约1,158样本/秒；该结果不包含DataLoader和CNN计算。

## 6. 两套未来评估方案

方案A，性能分层80/10/10：117,160 / 14,656 / 14,655。

方案B，时间外推：仅使用第541状态以后首次出现、且修复关联组没有早期成员的拓扑作为测试集。训练/验证/测试为118,857 / 13,218 / 14,396。

时间测试抽样512条、训练参考8192条的近邻汉明距离：最小4，中位数15，P90=18，最大22。它是固定抽样诊断，不是全训练库精确最近邻。

两种划分均无完全相同拓扑哈希泄漏，也无raw→corrected修复关联组跨集合。

## 7. 当前停止点

全项目测试结果：22 passed。

尚未完成、也没有声称完成：256样本过拟合、5,000–10,000样本短训练、Mini-Inception/ResNet18/VGG16模型训练、真实测试指标及10×10与90°语义输入效果比较。

下一阶段应先实现统一训练器和三个模型，再只跑256样本过拟合；链路通过后再进行短训练，最后才允许全量训练。
