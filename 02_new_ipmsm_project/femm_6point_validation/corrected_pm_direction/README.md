# 磁化方向修复后的单拓扑复现结果

## 关键修复

旧生成器把原本为Air或Iron的标签改成N38时只修改了材料，没有修改标签的 `magnetization_deg`。因此 `candidate_002/air0` 的128个PM标签中有76个仍为0°或方向错误，最大角度误差约178.875°。

修复后，每个PM标签按照参考FEM和MAT中 `draw.mN/draw.mS` 的规则赋值：

- 45–90°磁极径向向外；
- 0–45°磁极径向向内；
- 四个对称位置保持相反磁极关系；
- 128/128个PM标签的方向误差低于 `1e-9°` 才允许进入FEMM。

因此，`femm_6point_validation/generated_fem`、原 `validation_results.csv` 和 `extended_30deg` 中的旧数值不能用于历史回归判断。

## 当前最佳统一配置

```text
候选：candidate_002
材料：air0（code0=Air，code1=N38，code2/3=Pure Iron）
铁材料：参考FEM的21点非线性BH曲线
机械角：0, 3, 6, 9, 12, 15°
电流：theta_e=4*theta_m，三相余弦电流，幅值3.5 A
转矩历史符号：-1 × FEMM原始转矩
Tavg：trapz(T, angle)/15
DeltaT：max(T)-min(T)
```

六点反号后转矩为：

```text
2.260238850, 2.354835572, 3.103287096,
3.184127061, 2.844827900, 3.295493695 N·m
```

| 指标 | 历史值 | 重算值 | 相对误差 |
|---|---:|---:|---:|
| Tavg，梯形平均 | 2.858312028 | 2.852988780 | 0.186% |
| Tavg，六点算术平均（对照） | 2.858312028 | 2.840468362 | 0.624% |
| DeltaT，绝对峰峰值 | 1.067494755 | 1.035254846 | 3.020% |

平均转矩已经达到数值基本一致；波动值非常接近，但按约2%标准仍略超出，不能标记为完全通过。

## 单变量排查结果

| 变体 | 最佳/对应Tavg误差 | 峰峰值误差 | 判断 |
|---|---:|---:|---|
| air0、3°步长、非线性铁 | 0.186%（梯形） | 3.020% | 当前最佳 |
| air0、2.5°步长、非线性铁 | 2.112%（六点平均） | 11.607% | 排除为最佳角度组 |
| air2、3°步长、非线性铁 | 40.398%（梯形） | 5.595% | 排除 |
| air3、3°步长、非线性铁 | 29.229%（梯形） | 44.323% | 排除 |
| air0、3°步长、线性铁μr=4000 | 91.866%（梯形） | 94.319% | 明确排除 |

这些结果支持：参考FEM里的非线性Pure Iron才是历史使用的铁材料；MAT中的 `mu_Eisen=4000` 不能直接替代BH曲线；材料编码最可信的是 `air0`。

## 剩余3%波动误差

当前几何、材料映射、PM方向、角度组和平均公式均已有强证据。剩余波动差值为0.032240 N·m，更可能来自：历史 `DeltaT` 的具体后处理细节、参考FEM并非历史运行时的完全相同模板、FEMM版本/网格差异，或历史曲线还包含未保存的端点处理。没有MATLAB源码或一条历史六点原始转矩曲线，暂时不能唯一确定。
