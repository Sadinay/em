> **2026-08-21更正：** 本报告下方第1–8节记录的是发现PM磁化方向生成缺陷之前的实验，数值结论已经失效。旧生成器有76/128个新PM标签方向错误。修复后的有效结果见 `corrected_pm_direction/README.md`：当前最佳Tavg误差0.186%，DeltaT误差3.020%。旧内容仅保留用于审计追踪。

## 结论先行

两例 smoke 的建模和 FEMM 批处理流程已跑通，但历史标量没有复现。36/36 个独立角度任务成功；在所有样本必须共用同一材料映射、转矩符号和公式的前提下，最接近的组合为：

```text
材料映射：code 0 = Air, code 1 = N38, code 2/3 = Pure Iron（air0）
转矩符号：历史值 = -1 × FEMM原始转矩
Tavg：排除15°端点的前五点平均
DeltaT：max(T)-min(T)，绝对峰峰值
```

但该组合的 `Tavg` 平均相对误差仍为 29.923%，`DeltaT` 平均相对误差为 12.862%，远高于 0.5% 和 2% 阈值。因此 `air0` 只能称为“本次有限枚举中最接近的候选”，不能称为历史真实映射；六个历史角度和两个历史公式也均未确认。
