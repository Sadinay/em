## 15°周期检查

相隔15°的五对转矩绝对差分别为：

```text
T18-T3  : 0.497658 N·m
T21-T6  : 0.385549 N·m
T24-T9  : 0.180919 N·m
T27-T12 : 0.700722 N·m
T30-T15 : 1.698260 N·m
```

- 平均绝对差：0.692622 N·m
- 最大绝对差：1.698260 N·m
- 配对 RMSE：0.872255 N·m
- RMSE / 十点峰峰值：51.36%

因此，**当前重建与角度/电流设置下，15°不是闭合周期**。这不是网格或浮点误差等级的差异。

## 与历史标量比较

历史 `Tavg=2.858312 N·m`、`DeltaT=1.067495`。

- 十点平均：1.692753 N·m，Tavg相对误差40.78%；
- 后半段18–30°五点平均：1.826238 N·m，仍低36.11%；
- 十点绝对峰峰值：1.698260，DeltaT相对误差59.09%；
- 前半段3–15°五点峰峰值：1.003273，与历史DeltaT相差6.02%，但Tavg仍相差45.45%。

扩展到30°没有恢复历史结果。现有证据更指向转子零位/转动方向、相电流同步方向、滑动气隙角定义或参考FEM初始状态没有与历史 MATLAB 对齐，而不是“历史只多算了15–30°”这一单独原因。
